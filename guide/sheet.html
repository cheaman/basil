🌿 바질 키우기 — 구글 시트 연결 안내

처음 한 번만 하면 됩니다 · 10분쯤 · 교실 컴퓨터(크롬)에서 · 선생님 개인 구글 계정으로 로그인된 상태

연결하면 무엇이 좋아지나요

· 아이가 어느 패드에서든 자기 바질을 이어서 키웁니다 (지금은 패드마다 따로 저장)
· 교실 컴퓨터 선생님 화면에서 반 전체 바질을 한눈에 봅니다
· 패드마다 반 설정을 넣지 않고, 링크 하나를 클래스룸에 올리면 됩니다
· 자료는 선생님 구글 드라이브의 시트에만 저장됩니다 (다른 곳으로 가지 않습니다)

하는 차례

1
바질 앱을 열고 첫 화면 오른쪽 위 👩‍🏫 선생님 → 비밀번호 → 위쪽 단추 ☁ 구글 시트
2
창 안의 📋 스크립트 복사 → 구글 스크립트 새로 열기 ↗
열린 곳에 있던 글을 모두 지우고 붙여 넣기 → 저장(Ctrl+S) · 프로젝트 이름은 「바질 키우기」
3
오른쪽 위 [배포] → [새 배포] → 톱니바퀴 → [웹 앱]
· 다음 사용자 인증 정보로 실행 : 나
· 액세스 권한이 있는 사용자 : 모든 사용자 ← 이것이 아니면 연결이 안 됩니다
→ [배포] → [액세스 승인] → 계정 고르기
→ 「Google에서 확인하지 않은 앱」 이 나오면 [고급] → [바질 키우기(으)로 이동] → [허용]
선생님이 직접 붙여 넣은 스크립트라 괜찮습니다. 이 스크립트는 선생님 드라이브에 시트 하나를 만들고 그 시트만 씁니다.
4
나온 「웹 앱 URL」 을 복사 → 바질 앱 창의 칸에 붙여 넣기 → 🔌 연결 시험
「✔ 연결됐어요」 가 나오면 💾 저장하고 올리기 (통과하기 전에는 잠겨 있습니다)
5
창 아래 🔗 링크 복사 → 구글 클래스룸 «수업 자료» 에 붙여 올리기
아이들은 패드에서 그 링크를 누르고 → 자기 이름 → 그림 열쇠 3개로 들어갑니다
링크 안에 시트 열쇠가 들어 있습니다 — 클래스룸 안에만 올려 주세요

잘 안 될 때

앱에 나온 글이렇게 해 주세요
구글이 막았어요 — «액세스 : 모든 사용자»…3번에서 액세스를 모든 사용자로 바꿔 다시 배포
열쇠가 달라요바질 앱 창에서 스크립트를 다시 복사해 붙여 넣고 저장 → [배포 관리] → 연필 → 버전 「새 버전」 → [배포]
주소가 틀렸어요「웹 앱 URL」 을 다시 복사 (…/exec 로 끝나는 주소)
인터넷이 안 되거나 구글이 답하지 않아요잠시 뒤 다시 · 학교 와이파이가 구글 스크립트 주소를 막는지 정보 담당 선생님께 확인
스크립트를 고쳐 다시 올릴 때는 꼭 [배포 관리] → 「새 버전」 으로 — 「새 배포」 를 하면 주소가 바뀌어 링크가 끊깁니다.

수업 중에는

· 아이 화면 위쪽 작은 표시 : ☁✔ 저장됨 · ☁… 보내는 중 · ☁✘ 못 보냄 (패드에 모아 두었다가 와이파이가 이어지면 올림)
· 와이파이가 끊겨도 수업은 그대로 됩니다 — 이어지면 저절로 올라갑니다
· 시트(내 드라이브 「바질 키우기 · 반 이름」)의 「학생」 장에서 키 · 잎 · 건강 · 코인을 바로 볼 수 있습니다 — 시트 칸은 고치지 말아 주세요 (앱이 씁니다)
