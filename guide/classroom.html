0 · 먼저 — 바질 앱은 어디서 가져오나요

바질 앱은 내려받거나 설치하는 파일이 아닙니다. 인터넷 주소입니다.
교실 컴퓨터 크롬 주소창에 아래 주소를 치면 바로 열립니다 :
https://cheaman.github.io/basil/
끝에 ?test 를 붙이면 연습용 «시험반» 입니다. 우리 반 수업에는 ?test 없이 위 주소 그대로 여세요.
1
교실 컴퓨터 크롬 → 주소창에 cheaman.github.io/basil → Enter
2
주소창 오른쪽 ☆ 을 눌러 즐겨찾기에 넣어 두기 (다음부터 한 번에)
3
처음 열면 «⚙ 반 설정» 화면이 먼저 나옵니다 → 아래 «1 · 처음 한 번» 으로
이 컴퓨터에서 전에 ?test(시험반)로 써 보셨다면 «시험반» 이 그대로 열립니다 → 👩‍🏫 선생님 → ⚙ 설정 ▾ → ⚙ 반 설정 에서 우리 반 학년 · 반 · 명단으로 바꿔 저장하면 됩니다
클래스룸에 올릴 «반 들어가기 링크» 는 따로 받는 것이 아니라, 이 앱 안에서 반 설정 · 구글 시트 연결을 마치면 앱이 만들어 줍니다. 그래서 차례가 «앱 열기 → 반 설정 → 구글 시트 연결 → 링크 생김 → 클래스룸에 올리기» 입니다.

클래스룸에 올리는 것은 «반 들어가기 링크» 하나입니다. 이 링크를 누르면 패드가 우리 반 설정 · 명단을 저절로 받아 «내 이름» 화면이 열립니다.
앱 주소(cheaman.github.io/basil)만 올리면 패드마다 반 설정을 새로 해야 합니다 — 꼭 «반 들어가기 링크» 를 올려 주세요.

계정 두 개 — 하는 일이 다릅니다

계정무엇에 쓰나왜
선생님 개인 구글 (지메일)구글 시트 연결 (스크립트 · 시트) — 처음 한 번학교 계정은 «모든 사용자» 로 여는 스크립트를 학교가 막아 두었을 수 있어서. 자료는 선생님 드라이브의 시트에만 저장됩니다
학교 계정구글 클래스룸 — 링크 올리기 · 아이들이 링크 누르기반 · 학생이 학교 계정 클래스룸에 있어서
교실 컴퓨터 크롬에 두 계정이 함께 로그인돼 있어도 괜찮습니다. 클래스룸 창이 뜨면 오른쪽 위 계정이 학교 계정인지만 확인해 주세요.

1 · 처음 한 번 — 준비

1
반 설정 — 앱을 처음 열면 저절로 나옵니다 → 학년 · 반 · 학생 명단 · 수업 꼴을 정하고 저장
자세히는 아래 2번 줄
2
구글 시트 연결 — «구글 시트 연결 안내» 대로 (10분쯤 · 개인 구글 계정으로)
연결해야 «반 들어가기 링크» 가 생깁니다.
3
반 설정 고치기 — 다시 열 때는 선생님 화면 ⚙ 설정 ▾ → ⚙ 반 설정 (한 시간 수업이면 수업 진행 판 위 ⚙ 반 설정)
맨 위 수업 꼴을 고르고 저장 : 🕐 한 시간 미션 수업 (한 시간 안에 씨앗 → 수확 · 선생님이 미션 · 문제를 보냄) 또는 📅 2~3주 키우기 (실제 날짜대로 · 수업 요일마다 돌봄)
학생 명단도 여기에 (클래스룸 명단을 복사해 붙이면 이름만 골라 넣습니다)

2 · 어디서 가져오나 — «반 들어가기 링크»

수업 꼴링크가 있는 곳
📅 2~3주 키우기첫 화면 오른쪽 위 👩‍🏫 선생님 → 위쪽 ⚙ 설정 ▾ → ☁ 구글 시트 → 창 아래 «🔗 반 들어가기 링크»
🕐 한 시간 미션 수업첫 화면 👩‍🏫 선생님 → 수업 진행 판 위쪽 🏫 클래스룸에 (또는 ☁ 구글 시트 창)

3 · 올리는 법

가 · 단추로 (권함)

1
교실 컴퓨터 크롬에 학교 계정으로 로그인된 상태에서 바질 앱 선생님 화면을 엽니다
2
🏫 클래스룸에 올리기 (☁ 구글 시트 창 · «🔗 링크 복사» 옆) 또는 🏫 클래스룸에 (수업 진행 판 위쪽)
3
작은 클래스룸 창이 뜹니다 → 오른쪽 위 계정이 학교 계정인지 확인 → 반 고르기 → 무엇으로 올릴지 고르기 → 올리기
· 자료 (권함) — 아이들이 «수업» 탭에서 언제든 다시 누를 수 있음 · 낼 것 없음
· 과제 — 마감 · 점검이 필요할 때 (2~3주 마지막 날 «성장 카드 내기» 에 좋음)
· 공지 — 그날만 알릴 때
창이 안 뜨면 크롬 주소창 오른쪽의 «팝업 차단» 표시를 눌러 허용 해 주세요. 제목 칸이 비어 있으면 «🌿 바질 키우기 들어가기» 처럼 적어 주세요.

나 · 손으로 (단추가 안 될 때)

1
바질 앱 ☁ 구글 시트 창 → 🔗 링크 복사
2
클래스룸(학교 계정) → 그 반 → 수업 탭 → + 만들기 → 자료
3
제목 적기 → 추가(또는 링크 그림) → 링크 → 붙여 넣기 → 게시

4 · 아이들은 이렇게 엽니다

1
패드에서 클래스룸 (앱이나 웹) → 그 반 → 수업 탭 → 바질 자료 → 링크 누르기
2
내 이름을 누르고 들어가기
· 한 시간 미션 수업 : 이름만 누르면 시작 → 선생님이 보내는 미션 · 문제가 화면에 크게 뜸
· 2~3주 키우기 : 이름 → 내 그림 열쇠 3개 → 내 바질
3
다음 수업에도 같은 링크를 다시 누르면 됩니다 (내 바질 · 점수는 선생님 시트에 저장)
링크가 클래스룸 앱 안 창으로 열려도 그대로 쓰면 됩니다. 화면을 더 크게 쓰려면 첫 화면 «📲 앱으로 깔기» (패드마다 처음 한 번 · 선생님 시작 안내 8번).

5 · 다른 선생님이 쓰실 때

· 앱 주소는 모두 같습니다 : https://cheaman.github.io/basil/
· 선생님마다 자기 개인 구글 계정으로 «구글 시트 연결» 을 한 번 → 자기 반 설정 · 명단 → 자기 «반 들어가기 링크» 를 자기 클래스룸에 올리기
· 시트 · 링크가 선생님마다 따로라 반끼리 섞이지 않습니다
· 한 선생님이 여러 반을 맡으면 반마다 스크립트를 하나씩 (반마다 10분) — 반마다 링크가 따로 생깁니다
· 처음 보시는 선생님께는 이 안내 차례 쪽을 보내 드리면 됩니다 : https://cheaman.github.io/basil/guide/

잘 안 될 때

클래스룸 창에 우리 반이 없음창 오른쪽 위 계정을 학교 계정으로 바꾸기
클래스룸 창이 안 뜸크롬 주소창 오른쪽 «팝업 차단» → 허용 · 그래도 안 되면 «나 · 손으로»
아이가 링크를 눌렀는데 «반 설정» 화면이 나옴앱 주소만 올라간 것 — «반 들어가기 링크» (주소 끝에 #j= 가 붙은 것) 로 다시 올리기
아이 화면 위 ☁✘와이파이 확인 · 이어지면 저절로 올라감 · 계속이면 학교 와이파이가 구글 스크립트 주소를 막는지 정보 담당 선생님께
